# コミットメッセージのルール

## 書き方

```
種類: 何をしたか(日本語で短く)
```

- 頭の「種類」は英語、そのあとは日本語で書く
- 「何をしたか」は、未来の自分が履歴を見てわかるように短く具体的に
- 「なぜそうしたか」を残したいときだけ、Description欄に書く
- Issueを閉じるときは最後に `closes #番号` をつける

## 種類の一覧

| 種類 | 使うとき | 例 |
|---|---|---|
| feat | 新しい機能・ファイルを追加した | feat: 仕分けパズルの画面を追加 |
| fix | バグを直した | fix: 正解判定がずれる問題を修正 |
| style | 見た目だけを変えた(動きは変わらない) | style: ボタンの色を調整 |
| refactor | 動きを変えずにコードを整理した | refactor: 判定処理を関数に分ける |
| docs | READMEやドキュメントを書いた | docs: READMEに使い方を追記 |
| chore | 設定ファイルなど、その他の雑務 | chore: .gitignoreを追加 |

## 例

```
feat: 最初のページを追加
chore: 改行コードをLFに統一する設定を追加
feat: 学習記録をlocalStorageに保存 closes #3
```
